# Data Analytics Project

## Overview

This project explores data analytics through three main approaches: Descriptive Analytics, Predictive Analytics, and Prescriptive Analytics.

The project aims to explore data, identify meaningful patterns, build predictive models, and investigate optimization techniques to support data-driven decision-making.

It was developed as part of my learning journey in Data Science and Artificial Intelligence, providing practical experience with data analysis and analytical problem-solving.

**Dataset:** The project uses a large CSV dataset that could not be uploaded to this repository due to its file size. The analysis notebooks contain the code used to work with the dataset.

## Project Objectives

- Explore and understand the dataset.
- Identify patterns, trends, and relationships in the data.
- Apply descriptive analytics techniques to extract insights.
- Explore predictive analytics approaches.
- Investigate prescriptive analytics and optimization techniques.
- Develop practical data analysis and problem-solving skills.

## Tools and Technologies

- **Python** – Data processing and analysis.
- **Pandas** – Data manipulation and analysis.
- **Jupyter Notebook** – Interactive coding and analysis.
- **PyGAD** – Genetic algorithm implementation, where applicable.
- **Linear Programming** – Optimization techniques.

## Methodology

The project is organized into several notebooks, each focusing on a different analytical approach.

### 1. Descriptive Analytics

Explore the dataset and summarize its main characteristics to identify patterns and gain an understanding of the data.

### 2. Predictive Analytics

Analyze historical data to identify trends and patterns that can help estimate future outcomes. This section explores predictive analysis techniques without using Machine Learning models.

### 3. Prescriptive Analytics

Explore optimization techniques to investigate possible decisions or solutions based on analytical results.

### 4. Linear Programming and Genetic Algorithms

Explore optimization approaches, including Linear Programming and Genetic Algorithms, to solve optimization problems.

## Dataset

The dataset is stored locally and is not included in this repository because of its large file size.

To reproduce the analysis, the dataset must be available locally, and the notebook file paths may need to be adjusted accordingly.
